# Diseños de mascotas

- `mascotas/<especie>/<variante>/`: imágenes de referencia y posturas, organizadas por mascota.
- `referencias/`: imágenes de referencia generales proporcionadas para los diseños.
- `../public/pets/poses/trex/<variante>/`: posturas de T. rex ya exportadas con fondo transparente.
- `indice-archivos.csv`: ruta anterior y ruta actual de cada archivo reorganizado.

Los nombres descriptivos de las imágenes subidas se han asignado según su apariencia. Los archivos con sufijo `original` o `alternativa` se conservan como versiones adicionales. La organización no modifica la selección de mascotas de la aplicación ni integra las posturas en la interfaz.
