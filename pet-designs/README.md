# Diseños de mascotas

- `mascotas/<especie>/<variante>/`: imágenes de referencia y posturas, organizadas por mascota.
- `referencias/`: imágenes de referencia generales proporcionadas para los diseños.
- `mascotas/trex/<variante>/posturas-app/`: las 24 posturas transparentes usadas en la aplicación; el README de T. rex explica sus índices y fuentes.
- `indice-archivos.csv`: ruta anterior y ruta actual de cada archivo reorganizado.

Los nombres descriptivos de las imágenes subidas se han asignado según su apariencia. Los archivos con sufijo `original` o `alternativa` se conservan como versiones adicionales. Las posturas integradas también están en `../public/pets/poses/<especie>/<índice>/`.
