# T. rex: diseños y posturas

Cada carpeta contiene `posturas-app/` con los cuatro sprites transparentes usados en la aplicación. Se conservan aparte los originales y las correcciones de referencia; no se han sustituido los diseños originales verde y rojo.

| Aspecto en la aplicación | Carpeta | Índice en `public/pets/poses/trex` |
| --- | --- | --- |
| Jurásico | `verde/posturas-app` | 0 |
| Volcán | `rojo/posturas-app` | 1 |
| Laguna | `laguna/posturas-app` | 2 |
| Ciruela | `ciruela/posturas-app` | 3 |
| Desierto | `desierto/posturas-app` | 4 |
| Fósil | `fosil/posturas-app` | 5 |

Cada carpeta contiene `sentado.webp`, `durmiendo.webp`, `andando.webp` y `jugando.webp`. Son copias de las rutas numéricas utilizadas por la aplicación; mantén ambas sincronizadas al modificar un sprite.
